
# 六个世界 · Voxel Worlds

六个可交互的体素场景，全部由 DeepSeek V4.1 flash（1017 版）在 PTC 模式下，从一个中文提示词直接写成单文件 HTML。

- 在线游玩（raw.githack）：https://raw.githack.com/CCbitcode/voxel-worlds/main/site/index.html
- GitHub Pages：https://ccbitcode.github.io/voxel-worlds/ （在 Settings → Pages 开启后）
- 制作档案（提示词 / 流程 / 用时 / 花费）：site/archive.html
- 完整说明：site/README.md

本地运行：

```bash
cd site
python -m http.server 8088
```

然后打开 http://127.0.0.1:8088/ 。
